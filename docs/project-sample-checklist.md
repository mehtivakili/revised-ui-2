# چک‌لیست نمونه‌های آماده انواع پروژه

این فایل مرجع ادامه کار نمونه‌های صفحه «نوع پروژه» است. ترتیب ردیف‌ها دقیقاً با `venueTypes` در `src/domain/planner/venues.ts` یکسان نگه داشته می‌شود.

**پیشرفت فعلی: ۳۹ از ۳۹ نوع پروژه — تمام مرحله‌های ۱ تا ۸ تکمیل شده‌اند.**

## معیار تکمیل هر نمونه

- [ ] پلان متناسب با عنوان پروژه و تا جای ممکن جمع‌وجور و واقع‌گرایانه باشد.
- [ ] طبقات فقط در صورت نیاز اضافه شوند و گردش عمودی منطقی باشد.
- [ ] دیوارها، درها، پنجره‌ها و خروج‌های لازم به دیوار معتبر متصل باشند.
- [ ] مبلمان، تجهیزات و عناصر محوطه از کتابخانه فعلی طراح استفاده کنند.
- [ ] تمام فضاهای تشخیص‌داده‌شده نام و `sectionTypeId` معتبر داشته باشند.
- [ ] تمام بخش‌های حیاتی و مهم چک‌لیست کاربری در اتاق یا ناحیه اجباری نمایندگی شوند.
- [ ] نمونه از دکمه «باز کردن نمونه» روی کارت همان نوع پروژه قابل دسترس باشد.
- [ ] TypeScript، ESLint و تست‌های نمونه‌ها بدون خطا اجرا شوند.

## نمونه‌های مرجع سنگین

نمونه‌های `luxury-villa`، `retail-gallery`، `factory-campus`، `residential-parking`، `general-hospital`، `school-campus`، `kourosh-mall` و `mega-mall` حذف نمی‌شوند؛ این‌ها مرجع‌های پیشرفته‌اند و الزاماً نمونه اصلی دکمه روی کارت نیستند.
